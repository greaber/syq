# Python streams and mappings

Use byte streams for generated data or incremental reads, and mappings to
choose each entry's source and destination. See the [Python guide](python.md)
for examples and the [operations reference](python-operations.md) for client
configuration and shared arguments. [Results and exceptions](python-results.md)
apply across these interfaces.
