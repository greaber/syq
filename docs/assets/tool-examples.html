Dimmed choices are not provided by the command itself for these endpoints; scripts, mounts, or other tools may offer alternatives. “Workflow setup” compares ways to arrange a transfer.

Workflow setup

Send files home without an SSH server

syq

syq cp results --to @laptop

Run this on the server to send results to your laptop. The laptop needs no SSH server or incoming network port.

First set up a receiving connection from your laptop and name it laptop. Approve the incoming copy on your laptop. You can then send files from any server shell, including an existing tmux session.

Alternatively, initiate a pull from your laptop with rsync, scp, or rclone over SFTP; your laptop then needs no SSH server either. Syq’s receiving setup lets you initiate the copy from the server shell, with approval at home.

Set up receiving on your laptop

Copy between servers without agent forwarding

syq

syq cp --from hostA --srcs-in results --to hostB --into results

Run this on your laptop to copy the files inside hostA’s results folder directly into hostB’s results folder. File data travels between the servers.

Your laptop uses its SSH access to authorize the copy. Neither server needs your private keys or unrestricted access to your SSH agent. The servers must be able to connect for the transfer; see the guide for setup.

scp -3 and rclone with two SFTP remotes can also use your laptop’s logins without agent forwarding, relaying the data through your laptop. Rsync can run on the source server if that server has its own access to the destination. Syq combines laptop authorization with a direct data route.
